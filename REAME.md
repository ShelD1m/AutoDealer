# Система управления автосалоном (AutoDealer)

**AutoDealer** — это интерактивное консольное приложение, созданное для автоматизации повседневных задач автосалона.  
Программа берет на себя рутину по учету автомобилей, ведению клиентской базы и фиксации истории продаж, предоставляя удобный текстовый интерфейс для управления всеми процессами.

---

## Основной функционал

Приложение предлагает наглядное меню, через которое можно управлять ключевыми аспектами работы автосалона:

### Учет автомобилей (Каталог)
- Отображается актуальный список автомобилей
- Для каждой машины доступна информация:
    - **ID** (уникальный идентификатор)
    - **Марка и модель**
    - **Стоимость**

Позволяет быстро оценить доступный ассортимент.

---

### Ведение клиентской базы
- Список всех зарегистрированных клиентов
- Для каждого клиента отображается:
    - **ID**
    - **Имя и фамилия**
    - **Номер телефона**

Упрощает поиск клиента перед оформлением сделки.

---

### Оформление продаж (Регистрация сделок)

Ключевой модуль системы, процесс состоит из нескольких шагов:

1. Ввод **ID автомобиля**
2. Ввод **ID клиента**
3. Ввод **фактической цены продажи**  
   _(может отличаться от базовой стоимости, например, из-за скидки)_

После этого система:
- Связывает клиента с автомобилем
- Фиксирует дату продажи
- Сохраняет сделку в базе

---

### Аналитика (ТОП клиентов)

Модуль анализа продаж:
- Группирует сделки по клиентам
- Считает общую сумму покупок
- Показывает рейтинг клиентов по убыванию трат

Дополнительно отображается:
- Количество купленных автомобилей на клиента

---

## Как пользоваться программой

### Главное меню
После запуска отображается список всех доступных действий.

---

### Навигация
- Введите цифру (**1–4**) для выбора действия
- Нажмите **Enter**

---

### ️ Пошаговый ввод
Если операция требует данных (например, продажа):
- Программа выводит подсказки  
  _(например: `Введите ID машины:`)_
- Ожидает ввод пользователя

---

### Завершение работы
Для выхода из программы:
- Введите **0** в главном меню
